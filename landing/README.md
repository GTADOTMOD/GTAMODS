# GTAMOD site

A static site with no build step. Upload this folder, minus `tools/`, to any static host (Vercel, Netlify, Cloudflare
Pages). To look at it locally, serve the folder over http, because the page's scripts won't load from a `file://` address.

## What to change

`js/site-config.js` holds the links for X, GitHub and Discord, the optional official logos, and the download (see
[The download page](#the-download-page)). The X and GitHub marks sit in the nav and the footer and on the access buttons; an empty link hides a mark and turns a button into "opening soon".

**Official game logos** aren't included in this repository. The page shows the names as text; to show logos instead,
add the images to `assets/brand/` and list them under `logos` in `js/site-config.js`.

## The phone version

Phones and small windows, meaning anything under 900 px wide or 500 px tall, get their own version of the same page. `js/main.js`
picks one, using the same media query as the stylesheet link in `index.html`:

- **Phones:** `css/mobile.css` and `js/mobile.js`, with art from `assets/mobile/`. No 3D, no smooth-scroll library and no pinned
  scrolling: the page scrolls natively, the galleries are native swipes, and whatever moves is a transform or an opacity. The coins
  are flat pictures of the 3D coins, turned in CSS.
- **Desktops:** `js/desktop.js` and the 3D phone in `js/stage.js`. A phone never downloads these.

Change the words in `index.html` and both versions follow.

The drifting coins in Who we are and beside the RUGR icon reuse the phone version's coin pictures, from `assets/mobile/`, on desktops too.

## The story on desktops

Each of RUGR's six screens is its own shot, set in `SHOTS` in `js/desktop.js`: where the phone stands and how near, how it's turned, and which coin formation surrounds it. The formations are in `FORMS` in `js/stage.js`, one per shot, and the coins fly from one to the next. A step marked `data-side="right"` in `index.html` has its words on the right, so its shot puts the phone on the left. The coins keep clear of the words and the edges by themselves.

## The download page

`download.html` is where every "Get early access" button goes: the installer, what players need first, how to install
it, their first minutes in the game, safety, and help. It uses `css/site.css` plus its own `css/download.css`, which
also lays it out for phones, and `js/download.js`. It has no 3D, and phones get the same page in one column, with a
button to send it to a PC.

- **The file** is `RUGR-Setup-<version>.exe`, built by `installer\build-release.ps1` (see
  [installer/README.md](../installer/README.md)) and published on GitHub Releases. `download` in `js/site-config.js` has
  its address, version, size and SHA-256; the page fills them in. Installers are never committed to this repository.
- **The pictures of the installer** in `assets/install/` are its real screens, drawn by `RUGR-Setup.exe --capture`.
  Redraw them when the installer changes.
- **RUGR Setup links to this page**: `#play` from its last screen. Keep that id, and `#display`, which the first
  RUGR Setup build linked to from its screen-mode check.
- **Hosting:** Render's build command copies only what it lists, so it must include `download.html` and `downloads`.

## Artwork

The artwork in `assets/art/` was made for this site with OpenAI's image models: photorealistic, with invented people and
places, and labelled on the page as AI-generated and not from any game. Keep those labels, and never present the art as
screenshots or game footage. `assets/art/ingame-golden.webp` and `assets/art/coin-photo.webp` are real GTA V screenshots.

## Remaking the images

Everything in `assets/` is generated by the scripts in `tools/`:

```bash
npm install
```

- `generate-art.cjs` makes the photoreal images, using `OPENAI_API_KEY`. Delete an image in `art-source/` to make it again.
- `generate-icons.cjs` makes the icons, small 3D objects in the coins' gold and the phone's titanium on a see-through background, also with `OPENAI_API_KEY`, into `art-source/icons/`. `build-assets.cjs --only icons` trims them and saves them to `assets/icons/`.
- `capture-screens.cjs <fixtures folder>` draws RUGR's real phone page with sample data, without key hints or the Practice
  banner, for the 3D phone and the stills. It needs `COIN_PHOTO` pointing at the coin photo. The fixtures come from
  `node dist/test/fixtures.js <folder>` in `companion/`.
- `build-assets.cjs --shots <in-game screenshots folder> --photo <coin photo>` sizes the images, puts the current phone on the
  in-game frame, and builds the logo files, favicon and social image. Run it after `capture-screens.cjs`, then delete
  `assets/screens/*-framed.png`, which it only needs for that frame. It also makes the 3D coins' faces, in `assets/coins/`;
  `--only coins` makes just those. `--only mobile` makes the phone version's images in `assets/mobile/`.
- **GTAMOD's logo** is `brand/gtamod-logo.png`. `build-assets.cjs --only logo` trims it and makes
  `assets/brand/gtamod-logo*.webp` (the opening, the footer, the nav), `favicon.png` and the iPhone icon; `--only social` remakes
  the share image with it. The opening still flies through the original GTAMOD wordmark, from `js/wordmark.js`;
  `--only wordmark` remakes that, with `WORDMARK_FONT` pointing at Barlow Condensed 900's `.woff` file.
- `render-coins.cjs` draws each 3D coin once, for the phone version. Serve the site locally first, because it uses the site's own 3D code.
